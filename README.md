# Digital Forensics Investigation

A structured disk-image investigation and timeline reconstruction.

## Overview
I built a forensic workstation and investigated a disk image using a structured, methodical process - gathering evidence, analyzing artifacts, and reconstructing a timeline of events.

## What I did
- Set up a dedicated forensic workstation
- Investigated a disk image using a recognized public forensics dataset (NIST CFReDS)
- Performed structured data gathering and evidence analysis
- Reconstructed a timeline of activity and documented the findings

## Tools & Technologies
Digital forensics tooling, disk-image analysis, NIST CFReDS dataset

## Skills demonstrated
Forensic methodology, evidence handling, artifact and timeline analysis, investigative rigor, documentation

## Note
Summary of a lab exercise using a public forensics dataset. No private or sensitive data is included.
